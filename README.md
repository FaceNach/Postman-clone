# Postman Clone

## English

### Project Summary
Postman Clone is a desktop application that lets you test HTTP APIs from a simple interface.  
It supports common HTTP methods, validates request URLs, sends requests, and shows formatted JSON responses.

### Technologies Used
- C#
- .NET 8
- Windows Forms (WinForms)
- `HttpClient` for API requests
- `System.Text.Json` for JSON formatting

### Project Structure
- `PostmanCloneApp.sln`: Main Visual Studio solution file.
- `PostmanCloneUI/`: WinForms user interface project (dashboard and app startup).
- `PostmanCloneLibrary/`: Core logic for API calls, URL validation, and HTTP action definitions.
- `Images/`: Project images/resources.

## Español

### Resumen del proyecto
Postman Clone es una aplicación de escritorio que permite probar APIs HTTP desde una interfaz simple.  
Soporta métodos HTTP comunes, valida URLs de solicitud, envía peticiones y muestra respuestas JSON con formato.

### Tecnologías usadas
- C#
- .NET 8
- Windows Forms (WinForms)
- `HttpClient` para solicitudes API
- `System.Text.Json` para formateo JSON

### Estructura del proyecto
- `PostmanCloneApp.sln`: Archivo principal de solución de Visual Studio.
- `PostmanCloneUI/`: Proyecto de interfaz de usuario WinForms (dashboard e inicio de la app).
- `PostmanCloneLibrary/`: Lógica principal para llamadas API, validación de URL y definición de acciones HTTP.
- `Images/`: Imágenes/recursos del proyecto.
